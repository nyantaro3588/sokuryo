# 測点ノート — 総合サイト・学習解説

測量士補・土地家屋調査士の無料学習サイト「測点ノート」の総合入口と解説ページを管理するリポジトリです。

**公開サイト**: https://nyantaro3588.github.io/sokuryo/

## リポジトリの役割

| リポジトリ | 内容 | 公開URL |
| --- | --- | --- |
| [sokuryo](https://github.com/nyantaro3588/sokuryo) | 総合入口・測量解説・試験日/学習ペース | https://nyantaro3588.github.io/sokuryo/ |
| [sokuryo-quiz](https://github.com/nyantaro3588/sokuryo-quiz) | 測量士補の問題演習 | https://nyantaro3588.github.io/sokuryo-quiz/ |
| [sokuryo-calc](https://github.com/nyantaro3588/sokuryo-calc) | 座標法・面積・方向角・距離の計算 | https://nyantaro3588.github.io/sokuryo-calc/ |
| [gyosei](https://github.com/nyantaro3588/gyosei) | 行政書士の問題演習（別教材） | https://nyantaro3588.github.io/gyosei/gyosei_jissen.html |

## 本リポジトリの主なファイル

- `index.html`: 総合入口（新サイトへのリンク）
- `a1.html`〜`a4.html`: 座標法、方向角、水準測量、トラバース測量の解説
- `t3.html`: 試験日・学習ペース計算
- `t1.html`, `t2.html`: **旧URLの互換性を保つための移転案内**。本体は別リポジトリで管理
- `privacy.html`: プライバシーポリシー
- `sitemap.xml`, `sitemap.txt`, `robots.txt`: 検索エンジン向け設定

## 運用メモ

GitHub Pages は `main` ブランチの `/(root)` から公開します。

更新時は、記事やnoteで紹介されている旧URLを急に削除しないでください。問題集・計算ツールの実装は専用リポジトリで更新し、本サイトのリンク先を維持してください。
